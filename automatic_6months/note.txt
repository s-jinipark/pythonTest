
1. 매크로 설치
  https://github.com/needleworm/pywinmacro

2. 라이브러리 설치
  pip install pywin32 pyperclip

3. 매크로 사용하기 위한 방법
  코드를 실행시킬 폴더로 이동해서 그 폴더에 < pywinmacro.py > 를 복사한다
  그리고 아래와 같이 import
    >>> import  pywinmacro as pw
